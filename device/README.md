# Go-клиент режима собеседника

Самостоятельный модуль `alice-conversation/device` — клиентское ядро проекта «Алиса — режим собеседника» и команда `cmd/alice-ambient`. Это исходники для изучения и локальной сборки, **не готовая установка на колонку** и не официальный продукт Яндекса.

## Что делает код

- Принимает от внешнего источника PCM16 little-endian, 16 кГц, моно через приватный Unix datagram socket; сам микрофон не захватывает.
- Передаёт PCM серверу по защищённому WebSocket и принимает короткие текстовые ответы. Аудио и ожидающие ответы держит в ограниченных очередях оперативной памяти; в файл сохраняет только выбор `enabled`.
- Управляет очередью, отменой устаревших ответов, паузами и отправкой собственной реплики через Glagol. Потеря PCM или связи блокирует дальнейшую передачу и сбрасывает ожидающие данные.
- Предоставляет loopback HTTP: `GET /healthz` и защищённый Bearer-токеном `POST /control` с действиями `on`, `off`, `stop`, `reset`, `direct`.

**В этот модуль не входят** источник PCM, сервер обработки речи/модели, интеграция с Bridge, выдача токенов и сертификатов, установщик, VPN и настройка устройства. Проверки используют локальные подмены сервера и Glagol, синтетический PCM и временные сертификаты. Они не подтверждают работу настоящего микрофона, аппаратного mute, озвучивания или совместимость с конкретной колонкой.

## Проверки и сборка

Нужны Linux и **Go 1.27.3**, как указано в `go.mod`; для `-race` на Linux/amd64 также нужен C-компилятор. Тесты используют Unix sockets и loopback, включая адрес `127.84.32.9:1961`: порт должен быть свободен. При первом запуске Go может загрузить публичную зависимость.

Из корня этого модуля (каталог `device`):

```sh
export GOWORK=off GOFLAGS=-mod=readonly GOTOOLCHAIN=go1.27.3
go test -count=1 ./...
go test -race -count=1 ./...
go vet ./...
go mod verify

build_dir="$(mktemp -d)"
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -buildvcs=false -trimpath \
  -o "$build_dir/alice-ambient" ./cmd/alice-ambient
```

Последняя команда только собирает статический ARM64-бинарник во временном каталоге; она ничего не устанавливает и не запускает на устройстве.

## Границы безопасности

`config.example.json` содержит только пример: зарезервированный домен `.invalid`, адрес из RFC 5737 и условные абсолютные пути. Секреты и сертификаты в поставку не входят. Для отдельной интеграции нужны свои файлы: код требует режим `0600`, а для создаваемых каталогов состояния и сокета — `0700`; пути должны быть абсолютными, чистыми и различаться.

Сервер проверяется через доверенный CA; Glagol — по точному закреплённому сертификату с проверкой срока и назначения. HTTP-управление допускается только через loopback; перенаправления WebSocket запрещены. Не заменяйте эти проверки отключением TLS или открытым сетевым управлением. Здесь нет инструкции по получению доступа к устройству.
