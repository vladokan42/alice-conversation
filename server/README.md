# Python-сервер

Движок в `server.py`: aiohttp, Vosk и WebRTC VAD. Аудио распознаётся локально; в OpenAI-совместимый `/chat/completions` передаются только JSON-цитаты распознанной речи. Загрузка ASR-модели и постоянная запись разговоров не выполняются.

## Проверки без устройства

Из корня репозитория после установки зависимостей:

```sh
(cd server; ../.venv/bin/python -B -W error::ResourceWarning -m unittest discover -s tests -v)
.venv/bin/python -m pip check
```

Проверяются настоящий движок и локальные HTTP/WS; ASR, VAD, часы и текстовая модель в детерминированных сценариях подменены явно. Тестовые токены — открытые фиктивные строки, не доступ к сервису. Модель Vosk не нужна.

## Конфигурация исполнения

| Переменная | Значение |
|---|---|
| `CONVERSATION_TOKEN_FILE` | Свой обычный файл `0600` или строже: printable ASCII-токен, минимум 24 символа для приложения |
| `OMNI_BASE_URL` | Полный базовый URL текстового endpoint, включая `/v1`, без credentials/query/fragment; добавляется `/chat/completions` |
| `OMNI_KEY_FILE` | Свой файл ограниченного клиентского ключа gateway, минимум 16 символов, обычный файл `0600` или строже |
| `OMNI_MODEL` | Модель/alias твоего endpoint. Нейтральное значение по умолчанию `conversation-model` — пример, а не существующая модель |
| `CONVERSATION_MODEL_PATH` | Локальная папка Vosk, по умолчанию `/models/vosk-model-small-ru-0.22` |

Приложение не ищет общие credentials, не следует HTTP-redirect и не использует proxy environment. В файлах токенов запрещены symlink, FIFO, небезопасные права и пробельные символы внутри значения.

Промпт находится в константе `PERSONA`: это пример резкого разговорного характера, а не обязательная роль для чужой установки. Настраивать его нужно в своей копии. API не принимает системные инструкции из услышанного текста и не предоставляет модели инструменты управления устройствами.

## Локальная сборка контейнера

```sh
docker build -t alice-conversation-local ./server
```

В контейнере процесс UID/GID `1000:1000`, порт `8080`. Модель монтируется только для чтения; файлы токенов должны быть доступны этому UID и сохранять безопасные права.

Для своего запуска передай перечисленные переменные, свои secret-файлы и локальную модель через read-only mounts. Публикуй порт **только на loopback**, например `127.0.0.1:18864:8080`, а соединение от устройства принимай отдельным TLS gateway с авторизацией/ACL. Сам `python server.py` слушает `0.0.0.0:8080` и не реализует TLS — его нельзя бездумно запускать на внешнем интерфейсе. В репозитории нет готового production Compose или host-service unit.

## Интерфейс

- `GET /healthz`: только технические счётчики/состояние, без токена, URL, аудио, промпта или стенограммы. `upstream=unverified` не подтверждает доступность модели; HTTP 200 без клиента не означает готовую колонку.
- `GET /v1/listen`: WebSocket с Bearer-токеном; максимум один клиент, включая время завершения его обработчиков. Нет ключа — 401, занят — 409.
