# Безопасность и приватность

## Что передаётся

- Внешний источник на устройстве передаёт PCM Go-клиенту через приватный Unix socket; клиент — серверу по авторизованному TLS WebSocket.
- На сервере Vosk локально распознаёт речь. Текстовая модель получает ограниченный контекст распознанных фраз, без исходного аудио.
- Аудио, контекст и ожидающие реплики хранятся в RAM, клиент записывает только `enabled`. Health содержит фиксированные технические счётчики, не стенограмму.
- Это свойства приложения, **не гарантия всей среды**: swap, crash dumps, отладчики, администратор, reverse-proxy и провайдер модели могут иметь собственные механизмы хранения. Настрой их отдельно.
- Уже переданный провайдеру текст нельзя отозвать `cancel`: результат становится недействительным локально, но сетевой запрос завершается или достигает timeout.

## Условия безопасной интеграции

Используй режим только с ведома присутствующих. Клиент не определяет согласие и не отличает надёжно телевизор от разговора. Контроль аппаратного mute и отсутствие собственного эха должен обеспечивать внешний PCM producer вместе с интеграцией устройства.

Свой TLS gateway, ограниченные Bearer-токены, ACL и отсутствие внешнего порта — обязательные части собственной установки. Python entrypoint слушает `0.0.0.0:8080` без TLS; публикуй контейнер только на loopback. `GET /healthz` не требует токена и раскрывает техническое состояние. Не открывай его и `/v1/listen` напрямую в интернет.

Клиент проверяет сервер по своему CA; Glagol — по подтверждённому сертификату точного устройства. Не отключай эти проверки ради соединения. Сертификаты и токены не входят в комплект. Файлы секретов — обычные, без symlink, с правами `0600` или строже; собственные каталоги состояния — `0700`.

Конфиги и каталоги предполагаются доверенными локальными входами, а не песочницей для враждебного пользователя с теми же правами. Текст из разговора передаётся модели как недоверенная цитата. У модели нет инструментов/команд; вывод повторно проверяется, но семантическая корректность реплики не гарантируется.

## В репозитории нет

Рабочих ключей, сертификатов, конфигов колонки, домашних адресов, записей комнаты, стенограмм, весов моделей, изменённой прошивки, автозапуска на устройстве, VPN и закрытой Git-истории. Открытые тестовые токены и временные тестовые сертификаты не пригодны для реальной установки.

## Сообщение о проблеме

Не присылай токен, сертификат с private key, конфиг устройства или запись чужого разговора в публичный issue. Используй приватное сообщение владельцу либо GitHub private security advisory. Публикация исходников не является аудитом прошивки, всех зависимостей или сетевого контура.
