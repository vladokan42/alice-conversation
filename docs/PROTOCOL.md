# Протокол фонового режима

## Транспорт

Сервер: авторизованный WebSocket `/v1/listen` за TLS gateway. Один клиент одновременно; `Authorization: Bearer <свой токен>`. Go-клиент принимает только `wss`, проверяет сервер своим CA и запрещает redirect. Для Glagol нужен свой подтверждённый leaf-сертификат: сравнение точных байтов, проверка срока и назначения, без fallback на непроверенный TLS.

## От клиента серверу

Сначала и затем каждые 250 мс:

```json
{"type":"state","enabled":true,"blocked":false,"epoch":1}
```

`epoch` — целое от 0 до 2^63−1, без bool и строк. Старое состояние не обновляет heartbeat. Нет корректного состояния более 3 с — очистка и закрытие. До первого `state` аудио не обрабатывается.

Двоичные сообщения: PCM s16le, 16 кГц, моно. 1–6400 байт, длина чётная. Частичные фреймы объединяются в 20 мс/640 байт. Общая очередь вместе с исполняемым PCM и остатком ограничена двумя секундами/64 000 байт; превышение закрывает соединение.

Управление:

```json
{"type":"cancel","epoch":1}
{"type":"reset","epoch":1}
{"type":"spoken","epoch":1}
```

- `cancel` инвалидирует ожидающий ответ, но не стирает незавершённую тему.
- `reset` очищает контекст, сохраняя enabled. Допустимо запоздавшее намерение сброса с epoch не новее текущей.
- `spoken` сообщает о реальной отправке собственной речи и продлевает паузу.

Изменение поколения, off, блокировка или новая речь отменяют допустимость старого результата. Слот реального ASR/HTTP-обработчика не освобождается только потому, что его результат уже не нужен.

## От сервера клиенту

```json
{"type":"ready"}
{"type":"reply","epoch":1,"text":"Убери лишнее. Так будет проще."}
{"type":"cancel","epoch":1}
```

Сервер выдаёт до 350 символов и двух коротких предложений; JSON модели содержит ровно `speak` и `text`. Один внешний JSON code fence разрешён, разметка внутри озвучиваемого текста — нет. «Думаю», лишние поля/команды, nonfinite/повторные поля JSON отклоняются. Модель не получает tools.

Клиент повторно проверяет поколение, свежесть, тишину, блокировки и интервал 15 с перед отправкой в Glagol. На своей границе он допускает до 600 символов, но это не расширяет лимит сервера. Неотвеченный stale-запрос не должен останавливать чужую нативную реплику.

Коды закрытия сервера: `1008` — протокол/heartbeat; `1009` — размер; `1013` — переполнение; `1011` — ошибка обработки.

## Локальное управление Go-клиентом

Loopback `POST /control`, Bearer-токен, JSON до 1024 байт:

```json
{"action":"off"}
```

`on/off` меняют сохраняемый выбор, `stop` прерывает собственную реплику, `reset` сбрасывает тему. `direct` должен вызываться внешним адаптером **до** прямого обращения к Алисе. Потеря PCM временно блокирует обработку, не переписывает enabled. Источник PCM и интеграция аппаратного mute не входят в этот комплект.

Для синтетических интеграционных тестов используются собственные локальные TLS-сервисы и временные сертификаты. Это контракт, не свидетельство аппаратной приёмки.
