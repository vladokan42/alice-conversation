# Происхождение и состав

Публичное ядро существующего проекта Владислава Оканя «Алиса — режим собеседника». Это не новая языковая модель, не собственный ASR-движок и не официальный продукт Яндекса.

## Собственная часть

- Python: обработка состояния, ограниченные PCM-очереди, работа с ASR, вызов OpenAI-совместимого endpoint, строгий вывод, защита от устаревших ответов и локальные интеграционные проверки.
- Go: защищённый транспорт и Glagol, состояние режима, контроль mute/прерываний по поступающим событиям и PCM, безопасная локальная конфигурация, тесты.

Рабочие `.go`-исходники перенесены без изменения поведения. В двух тестовых файлах каталоги состояния теперь явно получают `0700`: первоначальный GitHub-прогон выявил зависимость `t.TempDir()` от umask среды. Проверки прав в приложении не ослаблялись; тесты пройдены при `0022` и `0077`. В Python заменено только локальное имя модельного alias по умолчанию на нейтральный `conversation-model`, с соответствующим тестом. Код безопасности, параметры очередей, пауз и персона не переписывались. Документация и CI подготовлены для самостоятельного публичного комплекта.

## Сторонние компоненты

`coder/websocket` v1.8.15 — ISC. Полное уведомление и текст лицензии: [THIRD_PARTY_NOTICES.txt](../device/THIRD_PARTY_NOTICES.txt). Go module/checksum manifest сохранены; сама библиотека не переименована в авторский код.

Сервер использует установленные отдельно aiohttp, Vosk API и WebRTC VAD с зависимостями из `server/requirements.txt`. Их авторские права и лицензии остаются у соответствующих проектов. Зависимости устанавливает package manager, их исходники и бинарные wheels здесь не переиздаются. Модели Vosk пользователь получает отдельно и проверяет их собственную лицензию.

Quasar Bridge, OmniRoute и Яндекс/Glagol упомянуты как внешние точки интеграции. Их исходники, прошивка, аккаунтные данные и домашняя инфраструктура не входят в комплект. Синтетический аудиоматериал локальной проверки также не распространяется.

## Что исключено

Локальные отчёты/замеры, устройства и сертификаты, приватные конфиги, веса, аудио, office/VPN/firewall/init/firmware scripts и история закрытого репозитория. Изменения публичного дерева не устанавливаются автоматически на работающий сервер или колонку.
